# Completed Tasks

This folder contains logs of completed tasks/sprints. Each file documents what was done, which files were changed, and any notes for future reference.

## Naming Convention

```
YYYY-MM-DD-short-description.md
```

## Template

```markdown
# Task: [Title]

**Completed:** YYYY-MM-DD
**Sprint:** [Sprint name from active-sprint.md]

## Summary
What was done.

## Files Created
- `path/to/new/file.ts` — purpose

## Files Modified
- `path/to/modified/file.ts` — what changed

## Notes
Anything a future agent should know.
```
